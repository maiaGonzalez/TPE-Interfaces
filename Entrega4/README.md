# TP-INTERFACES Ejercicio entregable N°4:

Desarrollar el juego “Peg Solitaire”:
1.Mostrar un tablero vacío (imagen de fondo).
2.Las piezas se dibujan con una imagen en lugar de un color sólido en base a la temática del juego. (Obligatorio: No tiene que ser color sólido, tienen que ser imágenes.)
3.El jugador tiene que poder mover (drag and drop) la fichas e ir jugando .(Obligatorio: Tiene que haber hints ANIMADOS indicando de donde puedo largar la ficha, se explican en clase. Ejemplo: Indicar arriba de los posibles lugares donde largar la ficha con flechas, hints, animaciones)
4.Se debe implementar la lógica del juego.
5.El juego termina cuando el jugador no tiene más movimientos posibles. Se debe verificar luego de cada movimiento de fichas si hay movimientos posibles.
6.Las fichas deben elegirse con click de mouse, y el usuario debe poder arrastrar la ficha y soltarla donde quiere. Solo si es valido la ficha caerá en el tablero.
7.Se debe poder reiniciar el juego, colocar un timer con el límite el tiempo del juego.
8.Integrar el juego en la página web presentada en el TPE2, el mismo debe poder ejecutarse desde la web. Debe contener las ayudas de cómo jugar y la descripción completa e imágenes del mismo.
9.Agregar diferentes tipos de fichas (colores o formatos) en base a la temática.
