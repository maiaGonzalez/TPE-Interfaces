# TP- INTERACES Ejercicio entregable N°2:
Este práctico contempla utilizar HTML5, JavaScript y CSS3 (animaciones simples) para continuar el trabajo anterior e Implementarlo. 
Para esto, se debe maquetar y diseñar en Alta las mismas páginas que las mencionadas en el trabajo anterior. No tiene que estar resuelto el backend del sitio, sino sólo estar diagramado lo que se necesite para la presentación del flujo que se muestra. 


1.El usuario debe poder interactucar con las 3 paginas descritas en el practico anterior.
2. Debe i cluir animaciones Hover en los botones: al menos 3 diferentes.
3. Al cargar la Home se debe ejecutar siempre un loading simulado de 5 segundos, el cual NO puede ser un GIF. El mismo debe mostrar un % de avance y una animación de carga (cuadrado, círculo, spinner)
4. Contener al menos una galería/carrusel de imágenes animada. Es decir que la transición entre imágenes de la galería están animadas. Puede ser por ejemplo en la página de descripción de un juego.
5. Los datos que se muestran do deben ser genéricos ni tampoco Loren Ipsum.
6.Diseño Mobile First: Se debe desarrollar	 el Home del sitio para las versiones mobile y desktop. (Aclaración: el resto de las páginas deberán ser desktop.)
